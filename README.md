# MO434 - Deep Learning

This repository contains materials, exercises, and assignments developed for the **MO434 - Deep Learning** course offered in the graduate program of the [Institute of Computing (IC)](https://ic.unicamp.br/) at the **University of Campinas (UNICAMP)**.

## About

The goal of this repository is to support the study of Deep Learning concepts and techniques covered throughout the course. It includes practical exercises and course assignments that explore topics such as:

- Neural Networks fundamentals
- Convolutional Neural Networks (CNNs)
- Recurrent Neural Networks (RNNs)
- Generative models
- Training techniques and optimization
- Applications of deep learning to real-world problems

## Structure

The repository is organized to reflect the progression of the course, with separate folders for each exercise set and assignment as they are released.

## Course

- **Course:** MO434 - Deep Learning
- **Program:** Graduate Program in Computer Science
- **Institution:** Institute of Computing (IC) - UNICAMP
- **Language:** Portuguese (lectures) / English (materials)

## Requirements

Most exercises and assignments use Python with deep learning frameworks such as [PyTorch](https://pytorch.org/) or [TensorFlow](https://www.tensorflow.org/). Specific dependencies will be listed within each exercise or assignment folder.
